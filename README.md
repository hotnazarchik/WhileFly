# WhileFly — FPV-помічник (React Native / Expo)

4 вкладки:

| Вкладка | Що робить |
|---|---|
| **Логи** | Відкриває Blackbox лог Betaflight (`.bbl/.bfl/.txt`), декодує бінарний формат прямо на телефоні: тривалість, батарея (просідання, мА·год), газ, навантаження кожного мотора, гіро, GPS, RSSI, режими/дізарми, PID/rates/фільтри, автоматичні висновки + графіки. Підтримує кілька польотів в одному файлі. |
| **Телеметрія** | Живі дані з ELRS Backpack: LQ, RSSI, SNR, TX power, батарея, GPS, відстань до дому, штучний горизонт, режим польоту, графіки та попередження. Протоколи CRSF і MAVLink (визначаються автоматично). Транспорти: Демо, WebSocket, UDP. |
| **Погода** | Обираєш місце (пошук або GPS), день, годину і борт → алгоритм дає **ймовірність вдалого польоту**, оцінку факторів, поради і найкращі години дня. |
| **Акаунт** | Профіль пілота, статистика нальоту, флот бортів (з допуском по вітру), історія всіх відкритих логів із нотатками; лог можна перевідкрити. |

## Запуск

1. Встанови [Node.js LTS](https://nodejs.org) (`winget install OpenJS.NodeJS.LTS`).
2. У цій папці:
   ```bash
   npm install
   npx expo install --fix
   npx expo start
   ```
3. Відскануй QR в **Expo Go** (Android/iOS).

> UDP-телеметрія використовує нативний модуль `react-native-udp`, тому для неї потрібен dev build:
> `npx expo run:android`. Демо і WebSocket працюють і в Expo Go.

## Як працює алгоритм погоди

- Прогноз: Open-Meteo (без ключа) — вітер на 10 і 80 м, пориви, опади, температура, точка роси, видимість, код погоди, схід/захід.
- Кожен фактор → оцінка 0..1 через плавні криві; вітер і пориви масштабуються під **допуск конкретного борту** (клас + вага).
- **Ймовірність** рахується по **ансамблю ICON-EPS (~40 сценаріїв)**: оцінка обчислюється для кожного сценарію і усереднюється — це реальна частка «льотних» сценаріїв. Узгодженість ансамблю = довіра до прогнозу.
- Після 7 днів (немає ансамблю) — детермінований прогноз, який з часом наперед зсувається до 50/50.

## ELRS Backpack

- **UDP**: ELRS у MAVLink-режимі / Backpack Wi-Fi шле пакети на UDP 14550 — додаток слухає порт.
- **WebSocket**: для мосту (ESP32/ПК), що віддає сирі CRSF/MAVLink байти (бінарно або hex-рядком).
- Парсер CRSF: GPS, Battery, Link Statistics, Attitude, Flight Mode, Vario, Baro. MAVLink: HEARTBEAT, SYS_STATUS, GPS_RAW_INT, ATTITUDE, GLOBAL_POSITION_INT, VFR_HUD, RADIO_STATUS (з перевіркою CRC).

## Сервер «Побратими» (акаунти й чати)

Папка `server/` — власний бекенд на Node.js (≥ 23.6): реєстрація за позивним, побратими (запити в друзі),
особисті й групові чати (загони) з доставкою в реальному часі (WebSocket), обмін логами польотів.
База — вбудований SQLite (`server/data/whilefly.db`), паролі хешуються scrypt, токени зберігаються в SecureStore.

```bash
cd server
npm install
npm start        # слухає порт 4000
npm test         # 20 наскрізних перевірок API
```

Адреса сервера для застосунку — у `.env` (`EXPO_PUBLIC_API_URL`) або в полі «Сервер» на екрані входу.
Щоб побратими могли писати не лише в твоїй Wi-Fi мережі — розгорни `server/` на VPS (будь-який з Node 24+).
